# PoliMi T2I

Study apps for my courses at Politecnico di Milano. Each folder is one course and runs on its own.

| Course | Folder | Run |
|---|---|---|
| Foundations of Artificial Intelligence (Fondamenti di AI) | [`Foundations-of-AI/`](Foundations-of-AI/) | `cd Foundations-of-AI && ./start.sh` |

Course materials (slides, past exams with solutions, exercise books) are **not** in this repository: they belong to
their authors. Put your own copies in the course folder; the apps run without them.
